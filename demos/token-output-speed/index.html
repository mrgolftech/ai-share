Token 是什么？

Token 是模型处理文本的基本单位。不同模型、语言和 tokenizer 的切分方式不同，本页只模拟输出节奏。

📖

看什么？

低速：等待感明显
中速：适合跟读
高速：更适合代码/批处理

🚀

别和 TTFT 混淆

TTFT：多久开始出字
Tokens/s：开始后吐字多快
Total：整个请求多久完成

怎么解读这个 Demo

先感受 Tokens/s

依次点击 5 → 20 → 50 → 100 tok/s，观察同一段内容从“等模型吐字”到“文本瞬间铺开”的主观变化。

这里的 Token 是视觉模拟片段，不是 Qwen/OpenAI 等模型的真实 tokenizer 结果，因此不要拿本页做性能基准。

再区分三个指标

TTFT 决定多久开始出字；Tokens/s 决定开始生成后的输出速度；Total Latency 决定整个请求多久结束。

Agent 会多轮调用模型和工具，因此即使单轮输出很快，TTFT、排队和多轮调用仍会累计成明显等待。
